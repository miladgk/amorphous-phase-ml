General Phase-ID output (17-feature model)
==========================================

Model: HistGradientBoostingClassifier on 17 features (see config_used.yaml).
Reference boxes: Cu50Zr50, Cu46Zr54, Cu64Zr36 (one simulation box each).
Target: polyamorphous box, 36,828 atoms, features averaged over 9 snapshots
(dt = 2 fs, timestep index step 1e6, so snapshots are about 2 ns apart).

Phase labels: 0 = Cu50Zr50, 1 = Cu46Zr54, 2 = Cu64Zr36.

Files written by train_and_predict.py
-------------------------------------
- model.pkl                Trained classifier (17 features) and training_meta
                           (feature order, class names, whitelist).
- config_used.yaml         Exact configuration of the run, including the feature
                           whitelist and the spatial consensus setting.
- predictions.csv          Per-atom table: target features with x, y, z,
                           predicted_phase_index, predicted_phase_name, confidence.
                           Not tracked by git (large); regenerate with the pipeline.
- predicted_phases.xyz     Extended XYZ for OVITO (species, x, y, z, phase,
                           confidence). Not tracked by git.
- phase_mapping.csv        Phase index -> name.
- validation_summary.json  Holdout accuracy, CV macro F1 (mean, std), confusion
                           matrix, per-class metrics, per-box split counts,
                           target phase fractions per threshold. Copied to
                           docs/assets/ and results/ by
                           scripts/generate_real_dashboard_data.py.
- permutation_importance.json  Top-10 permutation importance on the spatial
                           holdout (n_repeats = 10).
- norm_params.pkl, feature_ranges.pkl
                           Pooled reference mean/std and min/max used for
                           z-scoring and the out-of-distribution check.

Other files
-----------
- plots/                   Dark-mode figures (generated by scripts/generate_dark_figures.py).
- generate_visualizations.py   Deprecated wrapper that calls scripts/generate_dark_figures.py.

Validation (spatial holdout inside each reference box)
------------------------------------------------------
Each reference box is split at its median x: train x < median - 3.5 A,
test x > median + 3.5 A. The target box has no labels and is not used.
- Train / test atoms: 16,245 / 16,227 (test: Cu50Zr50 5,132, Cu46Zr54 5,137,
  Cu64Zr36 5,958). No rows are dropped.
- Holdout accuracy: 67.81 % (11,003 / 16,227).
- Per-class F1: Cu50Zr50 0.504, Cu46Zr54 0.590, Cu64Zr36 0.900.
- 5-fold stratified CV macro F1 on the training split: 0.670.
- Caveat: each reference phase is a single box, so the holdout does not test
  transfer across independent simulations.

Post-processing
---------------
Class probabilities are smoothed with a spatial consensus filter: each atom's
probabilities are blended with the mean of its neighbours within 3.6 A
(weight 0.35), with the periodic box read from the target dump file.
The regression R^2 = 0.938 quoted in earlier versions of this file is not part
of the current run and is not reported.

Interpreting the labels
-----------------------
Boundaries between predicted phases are classification decisions, not measured
transitions. Use the confidence column to separate reliable labels from
uncertain ones: at threshold 0.50, 15.6 % of atoms are uncertain; at 0.70,
64.1 % are (see the dashboard for the full table).
