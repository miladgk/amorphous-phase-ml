## Regenerating the recomputed tables

The settings are in `Atomic_Simulation_Post-Processing_Pipeline/outputs/README_recomputed.md`. In short:

1. Use `ANALYSIS_LEVEL: temporal_first_spatial` (uses `src/spatial_analysis_levels.py`, which is in the repository).
2. For each reference dataset, set `SNAPSHOT_DIRECTORY` to its folder and `output_csv` to the matching `outputs/features_<dataset>_recomputed.csv`. The composition is counted from each snapshot (`composition.compute_from_snapshot: true`), so `type_1_fraction` / `type_2_fraction` need no change (they only affect the CSRO columns, which are not in the model).
3. For the target, use `SNAPSHOT_DIRECTORY: "../Machine_Learning_Pipeline_for_Materials_Science/data/polyamorphous/"` (the default in `config.yaml`) and `output_csv: outputs/features_polyamorphous_recomputed.csv`. Raise `WORKER_TIMEOUT` (for example 20000 s) for the 36,828-atom frames.
4. Run `python src/pipeline_orchestrator.py --config config.yaml` from `Atomic_Simulation_Post-Processing_Pipeline/`.

Runtime: about 35 minutes for the target with one worker.

Then train and predict (from the repository root):

```bash
python Machine_Learning_Pipeline_for_Materials_Science/src/general_phase_id/train_and_predict.py \
    --config Machine_Learning_Pipeline_for_Materials_Science/src/general_phase_id/ref_config.yaml

# Dashboard data (writes docs/assets/ and assets/, copies validation_summary.json
# to docs/assets/ and results/), then figures
python scripts/generate_real_dashboard_data.py
python scripts/generate_dark_figures.py
```

`train_and_predict.py` writes `validation_summary.json`, `permutation_importance.json`, `norm_params.pkl` and `feature_ranges.pkl` to `general_phase_id_output/`; no summary is edited by hand. The numbers in the text of `docs/index.html` are still written in the HTML and must be updated by hand if the model changes.

## Timing of the target snapshots

The timestep index advances by 1e6 steps between the 9 target snapshots, with dt = 2 fs, so consecutive snapshots are about 2 ns apart. Time-correlation descriptors are therefore not meaningful for these data.
